# TAF iTicket.az

## Описание проекта

Test Automation Framework (TAF) для автоматизированного тестирования веб-приложения iTicket.az.

Проект включает UI и API автотесты, написан на Java и построен с использованием архитектуры Page Object Model (POM).

Для тестирования используется JUnit 5, для формирования отчетов — Allure Report, для CI/CD — Jenkins.

## Паттерны проектирования

### Page Object Model (POM)
Каждая страница веб-приложения представлена отдельным классом, содержащим:
- локаторы элементов
- методы взаимодействия с UI
- бизнес-логику страницы

Паттерн повышает читаемость кода и упрощает поддержку автотестов.

### Singleton
WebDriver реализован через паттерн Singleton для обеспечения одного экземпляра драйвера на протяжении выполнения тестов.

## Покрытие тестами

### Регистрация
- Успешная регистрация пользователя
- Проверка обязательных полей
- Валидация данных формы

### Авторизация
- Успешный вход пользователя
- Проверка некорректных данных
- Проверка сообщений об ошибках

### Восстановление пароля
- Отправка запроса на восстановление пароля
- Проверка обязательных полей
- Проверка уведомлений

### Поиск
- Поиск мероприятий
- Проверка результатов поиска
- Проверка корректности данных

## Структура проекта
```text

src
├── main
│   ├── java
│   │   └── az.iticket
│   │       ├── api
│   │       │   ├── client      # Клиенты для отправки API запросов
│   │       │   ├── endpoints   # Константы API endpoints (URL)
│   │       │   └── model       # DTO модели запросов и ответов
│   │       │
│   │       ├── basepage        # Базовый класс Page Object (общая логика UI)
│   │       ├── messages        # Тексты, сообщения и expected results для проверок
│   │       │
│   │       └── ui
│   │           ├── core        # Конфигурация WebDriver и настройка драйвера
│   │           └── pages       # Page Object классы UI страниц
│   │
│   └── resources
│       └── log4j2.xml          # Конфигурация логирования
│
├── test
│   ├── java
│   │   └── az.iticket
│   │       ├── api             # API тесты
│   │       ├── basetest        # Базовый класс для тестов (setup/teardown)
│   │       ├── ui              # UI тесты
│   │       └── utils           # Утилиты и генераторы тестовых данных
│
├── pom.xml                     # Maven конфигурация проекта
└── README.md                   # Документация проекта
---
```
Клонирование репозитория:
```bash
git clone https://github.com/YekaterinaS249/taf-iticket-az
```

```bash
cd taf-iticket-az
```

```bash
mvn clean install
```
