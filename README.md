# TAF iTicket.az

## Описание проекта

Test Automation Framework для автоматизированного тестирования веб-приложения iTicket.az.

Проект включает UI- и API-тестирование, реализован на Java с использованием Selenium WebDriver и REST Assured. Фреймворк построен с применением паттернов Page Object Model (POM) и Singleton. Для формирования отчетов используется Allure Report, а для автоматического запуска тестов настроена интеграция с Jenkins.

## Используемые паттерны

### Page Object Model (POM)

Каждая страница приложения представлена отдельным Page Object классом, содержащим локаторы элементов и методы взаимодействия с ними.

### Singleton

Для управления экземпляром WebDriver используется паттерн Singleton, обеспечивающий создание единственного экземпляра драйвера во время выполнения тестов.

## Покрытие тестами

### Регистрация

* Успешная регистрация пользователя
* Проверка обязательных полей
* Валидация данных формы регистрации

### Авторизация

* Вход зарегистрированного пользователя
* Проверка входа с некорректными данными
* Проверка сообщений об ошибках

### Восстановление пароля

* Отправка запроса на восстановление пароля
* Проверка обязательных полей формы
* Проверка отображаемых уведомлений

### Поиск

* Поиск мероприятий
* Проверка отображения результатов поиска
* Проверка корректности найденных данных

## Установка проекта

Клонировать репозиторий:

```bash
git clone <https://github.com/YekaterinaS249/taf-iticket-az>
```

Перейти в директорию проекта:

```bash
cd taf-iticket-az
```

Установить зависимости:

```bash
mvn clean install
```

---

## Запуск тестов

Запуск всех тестов:

```bash
mvn test
```

---

## Формирование Allure Report

Сгенерировать и открыть отчет:

```bash
allure serve target/allure-results
```

---

## CI/CD

Проект интегрирован с Jenkins для автоматического запуска тестов.

Возможности Jenkins:

* Автоматическая сборка проекта
* Запуск UI- и API-тестов
* Генерация Allure Report
* Мониторинг результатов выполнения тестов
* Хранение истории запусков
